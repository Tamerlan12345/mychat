# Design sources — Centras Chat light UI

Artboards of the approved design canvas (Claude Design `.dc.html` format):

- `Main.dc.html` — final 1440×900 chat screen: navigation rail, conversation list, timeline with states, composer, «О группе» panel.
- `Components.dc.html` — style sheet: color tokens, type scale, radii/shadows, buttons, inputs, list-row and message states.
- `LightOption.dc.html` — first light sketch (Variant B) kept for comparison.
- `canvas.json` — artboard layout, pages and sticky notes.

The token values documented in `Components.dc.html` are the ones implemented in `app/globals.css`
and mapped onto Tailwind classes (`gray-100/50`, `slate-900`, `gray-700/500`, `blue-600/700/50/200`).
Each artboard is a self-contained HTML file and can be opened directly in a browser for reference.
